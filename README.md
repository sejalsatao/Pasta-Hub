# 🍝 Pasta Hub

A responsive restaurant website built using HTML and CSS. The website provides an elegant interface for users to explore the restaurant, browse the menu, and access a table booking page.

## 🚀 Features

- Responsive homepage design
- Modern restaurant landing page
- Table booking interface
- Contact section
- Clean and user-friendly UI

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📁 Project Structure

```
Pasta-Hub/
├── index.html
├── style.css
├── photo/
└── README.md
```
